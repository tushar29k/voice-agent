voice-agent

BrightSmile Dental · demo receptionist

A voice receptionist for a dental clinic. The brain — intent detection, slot filling, function calls — runs on the server; speech recognition and speech synthesis are your browser's own Web Speech API. Turns are timed against an 800 ms backend latency budget so the conversation still feels like a phone call.

HOW IT WORKS

1 · You talk

The browser's speech recognition turns your voice into text — type instead if your browser doesn't support it.

2 · State machine

An explicit slot-filling flow (day → time → name → confirm) — no LLM free-for-all mid-call; voice can't afford meandering.

3 · Function calls

The agent calls the clinic's booking and order systems. Every call is timed and lands in the trace.

4 · It talks back

Your browser speaks the reply. Latency per turn is measured against the 800 ms budget — watch the meter.
